# Telegram Portfolio Showcase Bot

Профессиональный демонстрационный Telegram-бот для портфолио Senior Python разработчика на базе aiogram 3.x, асинхронного SQLite (aiosqlite) и машины состояний (FSM).

Бот объединяет в едином интерфейсе 4 готовых бизнес-сценария для демонстрации заказчикам.

---

## Демонстрационные бизнес-модули

1. **Интернет-магазин / Доставка еды (E-commerce):**
   - Интерактивный каталог блюд по категориям («Сеты», «Роллы», «Напитки»).
   - Детальные карточки товаров с динамическими счетчиками количества.
   - Корзина с расчетом промежуточных и итоговой сумм.
   - Пошаговое оформление заказа (FSM): Имя -> Телефон -> Адрес.
   - Электронный чек пользователю и отправка подробного заказа администратору.

2. **Онлайн-запись на услугу (Бронирование):**
   - Пошаговый мастер: Выбор услуги -> Выбор даты -> Выбор слота времени -> Телефон.
   - Сохранение записи в базе данных SQLite.
   - Просмотр активных записей и возможность отмены пользователем.
   - Оповещение администратора о новой брони / отмене.

3. **Калькулятор IT-услуг / Лидогенерация:**
   - Интерактивный квиз/опросник: Тип проекта -> Бюджетная вилка -> ТЗ/Описание -> Контакт.
   - Автоматическая фиксация лида в базе данных.
   - Мгновенный пересыл полного ТЗ и контакта администратору.

4. **О разработчике и Цены (Портфолио):**
   - Стек технологий (Python 3.12, aiogram 3, FastAPI, PostgreSQL, Redis, Docker).
   - Прайс-лист на типовые услуги.
   - Кнопки быстрой связи в Telegram и перехода в калькулятор.

5. **Панель Администратора (Защита по ADMIN_ID):**
   - Сводная аналитика (пользователи, заказы, сумма продаж, бронирования, лиды).
   - Просмотр последних заказов с деталями.
   - Массовая рассылка сообщений по всей базе пользователей с отчетом.

---

## Стек технологий

- Python 3.10+ (Python 3.12)
- aiogram 3.x (Асинхронный фреймворк для Telegram Bot API)
- aiosqlite (Асинхронная работа с SQLite)
- python-dotenv (Управление переменными окружения)

---

## Быстрый запуск

### 1. Установка зависимостей:
```bash
pip install -r requirements.txt
```

### 2. Настройка переменных окружения:
В файле `.env` (создайте на основе `.env.example`):
```env
BOT_TOKEN=your_telegram_bot_token_here
ADMIN_ID=your_telegram_id_here
```

### 3. Запуск бота:
```bash
python bot.py
```
База данных `demo_bot.db` и все таблицы с начальными товарами создадутся автоматически при первом старте.
