# Echo Sonar - HTML5 Canvas Audio-Visual Game

Браузерная аркадная игра на базе HTML5 Canvas 2D и Web Audio API, созданная для платформы Яндекс Игры.

---

## Особенности архитектуры

- **Рендеринг на чистом Canvas 2D:** Без тяжелых игровых движков, плавная отрисовка на 60 FPS.
- **Web Audio API:** Процедурная генерация звуковых импульсов эхолокации в реальном времени.
- **Yandex Games SDK:** Интеграция лидербордов, облачных сохранений и показа рекламы.
- **Адаптивность:** Корректное масштабирование под мобильные и десктопные экраны.

---

## Запуск проекта

Откройте файл `index.html` в браузере или запустите локальный статический сервер:
```bash
npx serve .
```
